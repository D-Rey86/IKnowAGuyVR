# Motion controller bindings

This guide applies to the VR package. The table below uses the default right-handed controls and Touch button labels. **Settings > VR > Motion controller bindings** shows the reference for your selected dominant hand and stick arrangement. Left primary/secondary correspond to X/Y on Touch and A/B on Index-style controllers.

| Action | Default control |
| --- | --- |
| Move | Left stick; smooth walking follows physical headset heading |
| Turn | Right stick; smooth or snap turning in VR settings |
| Cycle inventory slots | Right stick up/down during ordinary gameplay |
| Scroll menus | Turning stick up/down while pointing at a scrollable menu |
| Sprint | Hold left-stick click |
| Pause | Double-click left stick |
| Jump | A |
| Pizza recipes | X opens and closes |
| Cursor visibility | Right-stick click toggles only the active hand's pointer |
| Pick up or interact | Grip; either hand supports compatible targets |
| Keep holding an item | Quick grip press and release |
| Release after holding grip | Hold grip, then release |
| Use held item or use it on a target | Right trigger, including dough storage and pizza boxing |
| Secondary item use | Left trigger |
| Drop | Y |
| Build / sell | Tap B to build; hold B to sell |
| While placing | B confirms, Y cancels, triggers rotate |
| Back or exit a machine | B |
| Menus and pointers | Primary hand trigger or grip; other hand grip |
| Punch / bat | Physical swing; holding grip is not required for an equipped bat to hit |
| Camera | Left trigger enters photo mode; right trigger takes the picture |

The wrist dashboard displays time, money, debt, reputation, quests and orders. Select **Map** to open the map; B closes it. Select quest/order headings to collapse or expand them. Grab the pinned journal's title bar to reposition it. **While grabbed**, the turning stick rotates it left/right and moves it closer/farther up/down. Release to pin it. Pointing at the board does not block walking.

Grip an item miniature on the belt to equip it. Release over a loop to stow, move or swap it. Ingredient boxes retain their picture identifiers. Adjust belt height and distance in VR settings.

## Handedness and seated play

**Dominant Hand** switches the trigger and face-button actions shown below. Grip interactions stay on both hands. **Swap Motion Sticks** independently switches the movement and turning sticks and the actions attached to those sticks.

| Action | Right-handed (Touch) | Left-handed (Touch) |
| --- | --- | --- |
| Jump | Right A | Left X |
| Open or close recipes | Left X | Right A |
| Build, sell, confirm or go back | Right B | Left Y |
| Drop or cancel placement | Left Y | Right B |
| Use a held item or take a photo | Right trigger | Left trigger |
| Secondary item use or enter photo mode | Left trigger | Right trigger |
| Preferred menu pointer | Right trigger or grip | Left trigger or grip |
| Wrist display | Left wrist | Right wrist |

In teleport mode, hold the movement stick forward and aim with the hand opposite your selected dominant hand. Release the stick over a valid destination to teleport. With **Swap Motion Sticks** on, move, sprint and pause use the right stick. Turn, scroll, cycle inventory, toggle the cursor and adjust the grabbed journal with the left stick.

Enable **Seated Play**, sit in your normal playing posture, then use **Calibrate Seated Height**. Height Adjustment fine-tunes eye and hand height without changing world scale. Recalibrate after substantially changing posture.

## Picture and comfort settings

Resolution Scale uses the runtime-recommended per-eye width and height. At 100% it follows that recommendation; above 100% it supersamples. Scaling both dimensions means 150% is roughly 2.25 times as many pixels, not 1.5 times. The displayed resolution and presets respect runtime/GPU limits.

World Scale changes perceived size. Stereo Separation adjusts the runtime-derived eye spacing. Smooth and snap turning, snap angle, smooth-turn speed, and smooth/teleport movement are configurable. Wrist Display Size scales the complete dashboard from 50% to 400% of its compact default.

**Gamepad Mode** keeps headset tracking and stereo while using regular gamepad gameplay. **UI Mode** selects Immersive or Classic. **Desktop View** can reuse a VR eye or render an independent monitor view; Independent costs an additional view and restores native desktop mouse alignment.
